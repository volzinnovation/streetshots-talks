# Streetshots talks

Streetshots presentations and their source assets are in `talks/` and `assets/`.

## Sign labels and pictograms

For new slides comparing MobiData BW, Panoramax, Mapillary, OpenStreetMap or Synset Signset
Germany, look up the provider's original label in OpenSign Core. Use the
reviewed classifier target when discussing a model and the exact national sign
code when describing an inventory record. A representative pictogram can
illustrate a family of signs. Record the Core commit alongside the asset
attribution in the event directory so the delivered talk can be reproduced.
